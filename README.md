# Bike Buyers

## Project Overview

This project explores customer and purchase data to understand patterns related to bike buying. An interactive Excel dashboard brings together transformed data, pivot table summaries, slicers, KPI cards, and charts so users can filter the information and compare customer groups.

## Project Goal

Turn the source data into a clear, interactive summary that helps identify patterns among bike buyers and supports comparison across customer segments.

## Analysis Questions

- How do buyers and non-buyers compare across the available customer attributes?
- Which customer segments show differences in bike purchasing patterns?
- How do dashboard results change when filters are applied?
- Which patterns stand out in the charts and summary metrics?

## Analysis Workflow

1. Review the source data and prepare it for analysis.
2. Clean and transform fields as needed for consistent summaries.
3. Build pivot tables to aggregate and compare customer information.
4. Create dashboard cards and charts to present key measures and patterns.
5. Add slicers so users can explore filtered views of the data.
6. Review the dashboard and summarize the main observations.

## Features

- Data cleaning and transformation to prepare the dataset for analysis
- Pivot tables to aggregate and compare buyer information
- Slicers to interactively filter dashboard views
- Summary cards to surface key metrics
- Charts to visualize customer patterns and comparisons
- A consolidated dashboard for exploring the analysis

## Tools Used

- Microsoft Excel: data transformation, pivot tables, slicers, cards, and charts

## Topics Covered

- Dataset overview and preparation for analysis
- Data cleaning and transformation
- Buyer demographics and customer segmentation
- Comparing buyer and non-buyer groups
- Exploring how customer characteristics relate to bike purchases
- Summarizing results with pivot tables and key metric cards
- Filtering dashboard views with slicers
- Visualizing patterns and comparisons with charts
- Drawing insights from the dashboard to support business decisions

## How to Use the Dashboard

Use the slicers to select the customer groups or categories you want to review. The pivot table summaries, cards, and charts provide different views of the filtered data. Compare the resulting views to spot patterns, then validate observations against the underlying summaries.

## Notes

The findings depend on the fields and records available in the source dataset. Treat dashboard patterns as descriptive observations; additional context may be needed before making business decisions.
